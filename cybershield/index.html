How It Works

From Log Line to Slack in Seconds

01
Ingest
Wazuh agents on Windows endpoints forward logs via WireGuard VPN to the Wazuh Manager on your Hostinger VPS. Sysmon captures process creation, network, and file events.
02
Detect
Custom cybershield_rules.xml fires on brute force, USB events, Tor connections, and privileged group changes. MITRE ATT&CK IDs are tagged on every alert.
03
Analyze
n8n workflows at n8n.sarge.cloud query the Wazuh Indexer, call the Claude API via Sarge, and correlate findings across agents for context-rich analysis.
04
Brief & Respond
Daily 08:00 briefing posted to Slack. Critical events trigger immediate PagerDuty alerts. IncidentBot activates on RED events — isolation and AD lockout require one approval click.

Getting Started

Deploy in Four Steps

Full playbooks in /cybershield/playbooks/

1
VPS + Wazuh
Hostinger Ubuntu 22.04+, run bash wazuh-install.sh -a. See wazuh-hostinger-setup.md.
2
WireGuard + WinRM
Establish VPN tunnel, enable WinRM HTTPS on port 5986, create svc_cybershield service account.
3
n8n + Docker
Deploy Traefik + n8n via Docker Compose. Point n8n.yourdomain.com DNS. Import briefing workflows.
4
API Keys
Add keys for Anthropic, Shodan, VirusTotal, OTX, and HIBP to your .env. Load agent system prompts into n8n.
